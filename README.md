# Projeto Nextlvl-shop

Frontend de um ecommerce, feito com **Next js** + **Shadcn/ui**, com o propósito de colocar em prática conhecimentos em frontend e demonstrar domínio nas ferramentas usadas.

## Sobre o projeto

Este projeto foi criado com o objetivo de exercitar habilidades em:

- Next Js
- Server Actions
- Componentes UI (com a biblioteca Shadcn/ui)
- Boas práticas de estrutura de projetos frontend
- Deploy (Vercel) e manutenção
- Foco em simplicidade, legibilidade e organização
- Cálculo de frete

---

## Funcionalidades

- Carrinho de compras
- Paginação com app router
- Categorização de produtos
- Página de detalhes do produto
- Tela de pedidos já realizados com status
- Área de favoritos
- Busca de produtos
- Filtrar produtos por categorias, preço, etc...
- Validação básica (garantir que valores plausíveis sejam inseridos)
- Interface limpa, responsiva e clara

## Instruções para rodar localmente

### Pré-requisitos

- Node.js instalado (versão 12 ou superior recomendada).
- Next na versão 15 ou superior.
- Tailwind na Versão 4.0 ou superior.
- Shadcn/ui na versão latest (atual 1.0).

### Etapas:

<br>

1 - Inicialmente, clone o repositório:

```bash
git clone
```

<br>

2 - Acesse o diretório do projeto:

```bash
cd nextlvl-shop
```

<br>

3 - Instale as dependências:

```bash
npm install
```

<br>

4 - Rode em modo de desenvolvimento:

```bash
npm run dev
```
